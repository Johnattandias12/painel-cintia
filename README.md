# CintIA Dashboard

Analytics dashboard for public administration, fed by CintIA, a WhatsApp AI agent that talks to citizens. It turns those conversations into KPIs, an ombudsman view, a demand heatmap and trends that city managers can act on.

Live: https://painel-cintia.vercel.app

## What it shows

- Executive KPIs (requests, response time, satisfaction)
- Citizen feedback and ombudsman channel
- Heatmap of demand across the city
- Charts and trends over time

## Stack

Vanilla HTML, CSS and JavaScript with Chart.js. No build step, ships as a static site.
